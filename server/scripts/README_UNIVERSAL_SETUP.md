# Универсальный скрипт настройки базы данных

Этот набор скриптов предоставляет универсальное решение для проверки, создания и расширения структуры базы данных, а также для добавления тестовых данных.

## 📁 Файлы

- `universal_setup.js` - Основной универсальный скрипт
- `add_new_data_example.js` - Пример расширения функциональности
- `README_UNIVERSAL_SETUP.md` - Данная документация

## 🚀 Основные возможности

### universal_setup.js

**Автоматическая проверка и создание структуры БД:**
- Проверяет существование всех необходимых таблиц
- Создает отсутствующие таблицы
- Добавляет недостающие колонки в существующие таблицы
- Поддерживает внешние ключи

**Создание полного аккаунта юриста:**
- Офис с полной информацией
- Пользователь-администратор
- Сотрудник офиса
- Базовая статистика
- Данные для графиков

## 📋 Структура базы данных

Скрипт поддерживает следующие таблицы:

### offices
- Основная информация об офисе
- Контактные данные
- Финансовые показатели
- Данные ИП

### users
- Пользователи системы
- Аутентификация
- Роли и права доступа

### employees
- Сотрудники офиса
- Статистика работы
- Контактная информация

### office_stats
- Статистика офиса по периодам
- Посещения, заказы, выручка

### chart_data
- Данные для графиков и диаграмм
- Круговые и линейные диаграммы

## 🛠️ Использование

### Базовое использование

```bash
# Создание аккаунта юриста с проверкой БД
node scripts/universal_setup.js
```

### Программное использование

```javascript
const { 
  ensureDatabaseStructure, 
  createLawyerAccount,
  createOffice,
  createUser
} = require('./universal_setup');

// Только проверка и обновление структуры БД
await ensureDatabaseStructure();

// Создание аккаунта с кастомными параметрами
const result = await createLawyerAccount({
  officeName: 'Моя юридическая фирма',
  username: 'Иван Иванов',
  email: 'ivan@example.com',
  password: 'secure123',
  role: 'admin'
});

console.log('Создан аккаунт:', result.credentials);
```

## 🔧 Расширение функциональности

### Добавление новых таблиц

```javascript
const { DATABASE_SCHEMA, ensureDatabaseStructure } = require('./universal_setup');

// Расширяем схему
DATABASE_SCHEMA.new_table = {
  columns: {
    id: 'INTEGER PRIMARY KEY AUTOINCREMENT',
    name: 'TEXT NOT NULL',
    created_at: 'DATETIME DEFAULT CURRENT_TIMESTAMP'
  }
};

// Обновляем БД
await ensureDatabaseStructure();
```

## 🔒 Безопасность

- Пароли автоматически хешируются с помощью bcrypt
- Email генерируется с timestamp для уникальности
- Поддержка ролевой модели доступа
- Валидация данных на уровне БД

## 🐛 Обработка ошибок

- Автоматическая обработка конфликтов уникальности
- Откат изменений при ошибках
- Подробное логирование всех операций
- Graceful handling отсутствующих зависимостей

## 📈 Мониторинг

Скрипт выводит подробную информацию о:
- Проверке существования таблиц
- Создании новых таблиц
- Добавлении колонок
- Вставке данных
- Возникших ошибках

## 🔄 Повторное выполнение

Скрипт безопасен для повторного выполнения:
- Не создает дублирующие таблицы
- Не добавляет существующие колонки
- Генерирует уникальные email для пользователей
- Создает новые офисы при каждом запуске

## 🚨 Важные замечания

1. **Резервное копирование**: Всегда делайте бэкап БД перед запуском
2. **Тестирование**: Сначала тестируйте на тестовой БД
3. **Права доступа**: Убедитесь в наличии прав на изменение структуры БД
4. **Зависимости**: Проверьте наличие всех npm пакетов
