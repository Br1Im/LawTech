# Тестовые аккаунты

В этом файле представлены тестовые данные аккаунтов для различных ролей в системе LawTech.

## Аккаунты для тестирования

### 1. Юрист (Lawyer)
```json
{
  "id": 1,
  "username": "lawyer_test",
  "email": "lawyer@lawtech.com",
  "password": "lawyer123",
  "role": "lawyer",
  "firstName": "Анна",
  "lastName": "Петрова",
  "position": "Юрист",
  "department": "Юридический отдел"
}
```
**Доступные вкладки:**
- Офис
- AI инструменты
- Договоры
- Материалы
- Клиенты

### 2. Эксперт (Expert)
```json
{
  "id": 2,
  "username": "expert_test",
  "email": "expert@lawtech.com",
  "password": "expert123",
  "role": "expert",
  "firstName": "Михаил",
  "lastName": "Сидоров",
  "position": "Эксперт",
  "department": "Экспертный отдел"
}
```
**Доступные вкладки:**
- AI инструменты
- Сотрудники
- Материалы
- Клиенты

### 3. Администратор (Admin)
```json
{
  "id": 3,
  "username": "admin_test",
  "email": "admin@lawtech.com",
  "password": "admin123",
  "role": "admin",
  "firstName": "Елена",
  "lastName": "Иванова",
  "position": "Администратор",
  "department": "Администрация"
}
```
**Доступные вкладки:**
- AI инструменты
- Договоры
- Приходы
- Ресепшен
- Записи (количество записей на сегодня и завтра)

## Инструкции по использованию

1. Используйте указанные логин и пароль для входа в систему
2. После авторизации система автоматически определит роль пользователя
3. Меню будет отфильтровано в соответствии с ролью пользователя
4. Для тестирования различных ролей выйдите из системы и войдите под другим аккаунтом

## Примечания

- Все пароли указаны в открытом виде только для тестирования
- В продакшене пароли должны быть захешированы
- Роли определяют доступные функции и разделы системы
- Вкладка "Записи" для администратора должна показывать количество записей на сегодня и завтра
