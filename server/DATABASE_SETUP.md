# Инициализация базы данных LawTech

## Описание

Скрипт `init_database.js` предназначен для автоматической инициализации базы данных проекта LawTech. Он проверяет существование базы данных, создает все необходимые таблицы и заполняет их тестовыми данными.

## Возможности скрипта

- ✅ Автоматическое создание базы данных (если не существует)
- ✅ Создание всех необходимых таблиц с правильной структурой
- ✅ Настройка внешних ключей и индексов
- ✅ Заполнение тестовыми данными
- ✅ Создание тестового администратора
- ✅ Безопасное выполнение (не перезаписывает существующие данные)

## Структура базы данных

Скрипт создает следующие таблицы:

### Основные таблицы
- **offices** - Офисы компании
- **users** - Пользователи системы
- **employees** - Сотрудники
- **clients** - Клиенты
- **contracts** - Контракты

### Дополнительные таблицы
- **office_stats** - Статистика по офисам
- **calendar_events** - События календаря
- **messages** - Сообщения чата
- **legal_documents** - Юридические документы

## Настройка окружения

Создайте файл `.env` в папке `server` со следующими параметрами:

```env
# Database configuration
DB_HOST=localhost
DB_PORT=3307
DB_USER=root
DB_PASSWORD=password
DB_NAME=lawtech

# Server configuration
NODE_ENV=development
PORT=3001
JWT_SECRET=your-secret-key-here

# FAISS service
FAISS_SERVICE_URL=http://localhost:5000
```

## Безопасность

- Скрипт не удаляет существующие данные
- При повторном запуске пропускает создание тестовых данных
- Использует безопасное хеширование паролей (bcrypt)
- Поддерживает переменные окружения для конфигурации

## Устранение неполадок

### Ошибка подключения к БД
```
❌ Ошибка при создании базы данных: Access denied
```
**Решение:** Проверьте настройки в `.env` файле и убедитесь, что Docker контейнер с MySQL запущен.

### Отсутствие модулей
```
Error: Cannot find module 'bcryptjs'
```
**Решение:** Выполните `npm install` для установки зависимостей.

### Проверка состояния БД
```bash
# Проверка таблиц
docker exec -it lawtech-new-db-1 mysql -u root -ppassword -D lawtech -e "SHOW TABLES;"

# Проверка данных
docker exec -it lawtech-new-db-1 mysql -u root -ppassword -D lawtech -e "SELECT * FROM offices;"
```

## Программное использование

Скрипт можно использовать как модуль:

```javascript
const { initializeDatabase, createTables, seedData } = require('./init_database');

// Полная инициализация
await initializeDatabase();

// Только создание таблиц
await createTables();

// Только тестовые данные
await seedData();
```
