# Как увидеть изменения в чате 🔄

## Проблема
Docker контейнер пересобран, но изменения не видны в браузере.

## Решение

### Вариант 1: Жёсткая очистка кеша (рекомендуется)

#### Chrome / Edge
1. Открой DevTools (F12)
2. Кликни правой кнопкой на кнопку обновления (слева от адресной строки)
3. Выбери **"Очистить кеш и жёсткое обновление"** (Empty Cache and Hard Reload)

#### Firefox
1. Открой DevTools (F12)
2. Перейди в Network (Сеть)
3. Кликни правой кнопкой в любом месте
4. Выбери **"Очистить кеш"**
5. Обнови страницу (Ctrl+Shift+R)

### Вариант 2: Ручная очистка кеша

#### Chrome / Edge
1. Нажми `Ctrl + Shift + Delete`
2. Выбери "Изображения и другие файлы, сохранённые в кеше"
3. Период: "За всё время"
4. Нажми "Удалить данные"
5. Обнови страницу (F5)

#### Firefox
1. Нажми `Ctrl + Shift + Delete`
2. Выбери "Кеш"
3. Период: "Всё"
4. Нажми "Удалить сейчас"
5. Обнови страницу (F5)

### Вариант 3: Режим инкогнито
1. Открой новое окно в режиме инкогнито (Ctrl+Shift+N)
2. Перейди на http://localhost
3. Изменения должны быть видны

### Вариант 4: Проверка через DevTools

1. Открой DevTools (F12)
2. Перейди во вкладку **Network** (Сеть)
3. Поставь галочку **"Disable cache"** (Отключить кеш)
4. Обнови страницу (F5)
5. Проверь, что файл `ChatInterface.css` загружается заново

### Вариант 5: Добавить версию к CSS (если ничего не помогло)

Если браузер упорно не обновляет CSS, можно добавить версию к файлу:

1. Открой `frontend/src/components/AITools/ChatInterface.tsx`
2. Найди строку: `import './ChatInterface.css';`
3. Измени на: `import './ChatInterface.css?v=2';`
4. Пересобери контейнер

---

## Что должно быть видно после обновления:

✅ **Яркое золотое солнце** в центре экрана
✅ **Полупрозрачный фон** с эффектом размытия
✅ **Чат растянут** на всю высоту экрана
✅ **Широкое поле ввода** внизу (как в ChatGPT)
✅ **Сообщения на всю ширину** с чередующимся фоном

---

## Проверка, что контейнер пересобрался:

```bash
# Проверь, что контейнер новый (CREATED должен быть недавно)
docker-compose ps

# Проверь логи фронтенда
docker-compose logs frontend

# Проверь, что файл CSS внутри контейнера обновился
docker exec lawtech-frontend cat /usr/share/nginx/html/static/css/main.*.css | grep "goldenShimmer"
```

Если видишь `goldenShimmer` в выводе - значит CSS обновился!

---

## Если всё равно не работает:

1. Останови все контейнеры: `docker-compose down`
2. Удали образы: `docker-compose down --rmi all`
3. Пересобери с нуля: `docker-compose up -d --build --force-recreate`
4. Очисти кеш браузера
5. Открой в режиме инкогнито
