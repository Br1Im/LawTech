## ✨ Анимации

### Типы анимаций

#### 1. Появление элементов
```css
.fade-in-up      /* Появление снизу с прозрачности */
.slide-in-left   /* Появление слева */
.slide-in-right  /* Появление справа */
.scale-in        /* Масштабирование */
```

#### 2. Интерактивные эффекты
- **Hover**: Увеличение + тень
- **Active**: Уменьшение при клике
- **Focus**: Подсветка границы

#### 3. Специальные эффекты
- **Pulse**: Пульсация для активных элементов
- **Shimmer**: Эффект загрузки
- **Rotate**: Вращение иконок

### Примеры использования

#### Базовая анимация
```tsx
<div className="my-element fade-in-up">
  {/* контент */}
</div>
```

#### С задержкой
```tsx
<div 
  className="scale-in"
  style={{ animationDelay: '0.2s' }}
>
  {/* контент */}
</div>
```

#### Последовательное появление
```tsx
{items.map((item, index) => (
  <div 
    key={item.id}
    className="fade-in-up"
    style={{ 
      animationDelay: `${index * 0.1}s`,
      animationFillMode: 'both'
    }}
  >
    {/* контент */}
  </div>
))}
```

## ❓ FAQ

### Анимации не работают

**Проблема**: Элементы появляются без анимаций

**Решение**:
1. Проверьте, что все CSS файлы подключены в Office.tsx
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте консоль на ошибки
4. Убедитесь, что `prefers-reduced-motion` не активен

### Некорректное отображение на мобильных

**Проблема**: Элементы обрезаются или перекрываются

**Решение**:
1. Проверьте viewport meta tag в index.html
2. Убедитесь, что OfficeMobile.css загружен
3. Проверьте поддержку браузера
4. Очистите кэш

### Медленные анимации

**Проблема**: Анимации тормозят или лагают

**Решение**:
1. Проверьте производительность устройства
2. Отключите сложные эффекты в настройках
3. Используйте `prefers-reduced-motion`
4. Проверьте загрузку CPU/GPU

### Графики не отображаются

**Проблема**: Вместо графиков пустые блоки

**Решение**:
1. Проверьте, что данные загружаются с сервера
2. Проверьте консоль на ошибки
3. Убедитесь, что Chart.js установлен
4. Проверьте формат данных

### Модальные окна не открываются

**Проблема**: Клик по кнопке не открывает модальное окно

**Решение**:
1. Проверьте консоль на ошибки
2. Убедитесь, что обработчики событий работают
3. Проверьте z-index модального окна
4. Проверьте состояние в React DevTools

## 🔧 Настройка

### Изменение цветов

Отредактируйте CSS переменные:

```css
:root {
  --color-accent: #4476F0;
  --color-accent-light: #E8EEFF;
  --color-accent-dark: #2856C8;
  --color-bg: #FFFFFF;
  --color-bg-alt: #F8F9FA;
  --color-text: #333333;
}
```

### Изменение скорости анимаций

```css
.office-card {
  animation-duration: 0.3s; /* Быстрее */
}

.chart-box {
  transition-duration: 0.5s; /* Медленнее */
}
```

### Отключение анимаций

```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
```

## 🎓 Лучшие практики

### DO ✅

- Используйте CSS-анимации для простых эффектов
- Применяйте `transform` и `opacity` для производительности
- Тестируйте на реальных устройствах

- Не используйте слишком много одновременных анимаций
- Не забывайте про accessibility
- Не полагайтесь только на hover для мобильных
- Не делайте анимации слишком медленными (>1s)
