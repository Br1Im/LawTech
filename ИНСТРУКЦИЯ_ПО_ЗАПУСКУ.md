# Инструкция по запуску обновлённой CRM системы

## Быстрый старт

### 1. Установка зависимостей

```bash
cd frontend
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется на `http://localhost:5173`

### 3. Запуск через Docker (альтернатива)

```bash
# Из корневой директории проекта
docker-compose up --build
```

## Основные компоненты

### Сайдбар
- **Развёрнутый**: показывает календарь, иконки и названия пунктов меню
- **Свёрнутый**: только иконки, календарь скрыт
- **Мобильный**: выдвижное меню с кнопкой-гамбургером

### Календарь
- Навигация по месяцам
- Выделение текущего дня
- Выбор даты
- Поддержка обеих тем

### Навигация
- Офис
- Клиенты
- Договоры
- Календарь (полная версия)
- Записи
- Сотрудники
- Приходы
- Расходы
- Ресепшен
- Материалы
- AI инструменты

## Горячие клавиши

- `Ctrl/Cmd + B` - свернуть/развернуть сайдбар (планируется)
- `Esc` - закрыть мобильное меню

## Решение проблем

### Не запускается npm run dev
```bash
# Удалите node_modules и переустановите
rm -rf node_modules package-lock.json
npm install
npm run dev
```

### Ошибки TypeScript
```bash
# Проверьте версию TypeScript
npm list typescript

# Переустановите зависимости
npm install
```

### Проблемы с Docker
```bash
# Пересоберите контейнеры
docker-compose down
docker-compose up --build
```
