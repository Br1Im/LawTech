# 🏢 Автоматический выбор первого офиса

## ✅ Что исправлено

Добавлена функциональность автоматического выбора первого офиса при загрузке страницы.

## 🎯 Проблема

После перезагрузки страницы ни один офис не был выбран, и пользователь не понимал, информация про какой офис отображается.

## 🔧 Решение

### 1. Добавлен useEffect для автоматического выбора

```typescript
// Автоматически выбираем первый офис при загрузке
useEffect(() => {
  if (!selectedOffice && offices.length > 0) {
    console.log("Автоматически выбираем первый офис:", offices[0]);
    setSelectedOffice(offices[0]);
  }
}, [offices]);
```

### 2. Исправлена логика с officeFromContext

```typescript
// Обновляем данные из контекста только если есть значение
useEffect(() => {
  if (officeFromContext && officeFromContext !== null) {
    console.log("OfficeContext данные:", officeFromContext);
    setSelectedOffice(officeFromContext as unknown as SetStateAction<Office | null>);
  }
}, [officeFromContext]);
```

### 3. Восстановлены стили подсветки

```css
.office-card.selected {
  background-color: var(--color-accent-light);
  border: 3px solid var(--color-accent);
  box-shadow: 0 4px 12px rgba(68, 118, 240, 0.3);
  transform: scale(1.02);
}
```

### 4. Добавлена CSS переменная

```css
:root {
  --color-bg-hover: #e9e9e9;
  --color-accent-light: #E8EEFF;
}
```

## 📊 Результат

Теперь при загрузке страницы:

1. ✅ **Первый офис автоматически выбран**
2. ✅ **Яркая подсветка** (светло-синий фон + толстая синяя рамка + тень)
3. ✅ **Легкое увеличение** (scale 1.02)
4. ✅ **Пользователь сразу видит**, какой офис активен
5. ✅ **Подсветка остается** до выбора другого офиса

## 🔍 Как проверить

1. Откройте страницу "Офис"
2. Обновите страницу (Ctrl+R или F5)
3. Первый офис должен быть выбран с яркой подсветкой
4. Кликните на другой офис - подсветка переместится
5. Обновите снова - первый офис снова выбран
