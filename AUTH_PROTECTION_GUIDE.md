# 🔐 Руководство по защите авторизации в CRM

## ✅ Что было реализовано

### 1. Компонент ProtectedRoute
**Файл**: `frontend/src/components/ProtectedRoute.tsx`

Защищает маршруты от неавторизованных пользователей:
- ✅ Проверяет наличие токена
- ✅ Проверяет валидность токена (срок действия)
- ✅ Показывает загрузку во время проверки
- ✅ Автоматически перенаправляет на `/auth` если не авторизован

### 2. Утилиты авторизации
**Файл**: `frontend/src/shared/utils/authUtils.ts`

Набор функций для работы с авторизацией:


### 3. Защищенные маршруты

### 4. Автоматический перехватчик 401
**Файл**: `frontend/src/main.tsx`

При получении 401 ответа от сервера автоматически выполняется выход:

```typescript

```

### 5. Редирект авторизованных пользователей
**Файл**: `frontend/src/pages/AuthPage.tsx`

Если пользователь уже авторизован и заходит на `/auth`, его перенаправляет на `/crm`:

```typescript
useEffect(() => {
  const token = localStorage.getItem('token');
  if (token) {
    navigate('/crm', { replace: true });
  }
}, [navigate]);
```

## 🔄 Поток авторизации

### Вход в систему:
1. Пользователь заходит на `/auth`
2. Вводит логин и пароль
3. При успешной авторизации:
   - Токен сохраняется в `localStorage`
   - Перенаправление на `/crm`

### Доступ к защищенным страницам:
1. Пользователь пытается зайти на `/crm`
2. `ProtectedRoute` проверяет:
   - ✅ Есть ли токен?
   - ✅ Валиден ли токен?
3. Если проверки пройдены:
   - ✅ Показывается страница
4. Если проверки не пройдены:
   - ❌ Редирект на `/auth`

### Автоматический выход:
1. Токен истекает или становится невалидным
2. При следующем запросе к API:
   - Сервер возвращает 401
   - Перехватчик ловит 401
   - Автоматически выполняется `logout()`
   - Пользователь перенаправляется на `/auth`

## 🔧 Использование в новых компонентах

### Защита нового маршрута:
```tsx
// В App.tsx
<Route path="/new-page" element={
  <ProtectedRoute>
    <NewPage />
  </ProtectedRoute>
} />
```

### Использование утилит в компоненте:
```tsx
import { isAuthenticated, logout, getUserFromToken } from '../shared/utils/authUtils';

const MyComponent = () => {
  // Проверка авторизации
  if (!isAuthenticated()) {
    return <Navigate to="/auth" />;
  }
  
  // Получение данных пользователя
  const user = getUserFromToken();
  
  // Выход из системы
  const handleLogout = () => {
    logout();
  };
  
  return (
    <div>
      <p>Привет, {user?.name}!</p>
      <button onClick={handleLogout}>Выйти</button>
    </div>
  );
};
```

## 🚨 Важные замечания

### 1. Токен в localStorage
- ✅ Токен хранится в `localStorage`
- ✅ Автоматически удаляется при выходе
- ⚠️ Не храните чувствительные данные в токене

### 2. Проверка на клиенте
- ✅ Базовая проверка на клиенте (быстро)
- ✅ Полная проверка на сервере (безопасно)
- ⚠️ Клиентская проверка - это UX, не безопасность

### 3. Срок действия токена
- ✅ Токен имеет срок действия (exp)
- ✅ Автоматически проверяется
- ⚠️ Настройте срок на сервере (рекомендуется 24 часа)

### 4. Refresh токены
- ⚠️ В текущей реализации нет refresh токенов
- 💡 Рекомендуется добавить для production
