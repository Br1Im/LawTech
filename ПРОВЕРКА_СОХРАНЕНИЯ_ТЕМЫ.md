# Пошаговая проверка сохранения темы 🔍

## Контейнеры пересобраны! ✅

---

## 📋 Шаг 1: Очисти кеш браузера

### Вариант A: Режим инкогнито (РЕКОМЕНДУЕТСЯ)
```
Ctrl + Shift + N (Chrome/Edge)
→ http://localhost
```

### Вариант B: Жёсткая очистка
```
F12 → Правый клик на обновление → Empty Cache and Hard Reload
```

### Вариант C: Полная очистка
```
Ctrl + Shift + Delete → Кеш → За всё время → Удалить
→ Закрой и открой браузер
```

---

## 📋 Шаг 2: Проверь сохранение темы

### 1. Открой сайт
```
http://localhost
```

### 2. Переключи на тёмную тему
- Найди иконку луны/солнца в правом верхнем углу
- Кликни на неё
- Тема должна стать тёмной

### 3. Проверь localStorage
1. Открой DevTools (F12)
2. Перейди во вкладку **Console** (Консоль)
3. Введи команду:
```javascript
localStorage.getItem('theme')
```
4. Должно вернуть: `"dark"` ✅

### 4. Обнови страницу
- Нажми F5 или Ctrl+R
- Тема должна остаться тёмной ✅

### 5. Проверь снова localStorage
```javascript
localStorage.getItem('theme')
```
- Должно вернуть: `"dark"` ✅

### 6. Переключи обратно на светлую
- Кликни на иконку
- Тема должна стать светлой

### 7. Проверь localStorage
```javascript
localStorage.getItem('theme')
```
- Должно вернуть: `"light"` ✅

### 8. Обнови страницу
- Нажми F5
- Тема должна остаться светлой ✅

## 🔧 Если тема всё равно слетает

### Проверка 1: Убедись что изменения применились
```javascript
// В консоли браузера (F12 → Console)
console.log('Тема из localStorage:', localStorage.getItem('theme'));
console.log('Тема в HTML:', document.documentElement.getAttribute('data-theme'));
```

Оба значения должны совпадать!

### Проверка 2: Проверь что код обновился
1. Открой DevTools (F12)
2. Перейди во вкладку **Sources** (Источники)
3. Найди файл с компонентом (например, CRM)
4. Найди строку с `localStorage.setItem('theme'`
5. Если её нет - кеш не очистился!

### Проверка 3: Принудительная очистка
```javascript
// В консоли браузера
localStorage.clear();
sessionStorage.clear();
location.reload(true);
```

### Проверка 4: Другой браузер
Попробуй открыть в другом браузере:
- Chrome
- Firefox  
- Edge

## 🎯 Ожидаемое поведение

### ✅ Правильно:
1. Переключаешь тему → она меняется
2. Обновляешь страницу → тема сохраняется
3. Закрываешь браузер → открываешь снова → тема сохраняется
4. Переходишь на другую страницу → тема одинаковая

### ❌ Неправильно:
1. Переключаешь тему → она меняется
2. Обновляешь страницу → тема сбрасывается на светлую

## 🐛 Отладка

### Добавь логирование в консоль:
```javascript
// Открой консоль (F12 → Console)
// При загрузке страницы должно появиться:
console.log('Загружена тема:', localStorage.getItem('theme'));

// При переключении темы должно появиться:
console.log('Сохранена тема:', localStorage.getItem('theme'));
```

### Проверь что localStorage работает:
```javascript
// Тест записи
localStorage.setItem('test', 'hello');
console.log(localStorage.getItem('test')); // Должно вернуть "hello"
localStorage.removeItem('test');
```

Если тест не работает - проблема с localStorage в браузере!
