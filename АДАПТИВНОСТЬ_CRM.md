# Полная адаптивность CRM системы

## Обзор

Система полностью адаптирована для всех устройств с плавными переходами и оптимизацией для touch-устройств.

## Поддерживаемые разрешения

### 📱 Мобильные устройства
- **320px - 480px** - Маленькие телефоны (iPhone SE, старые Android)
- **481px - 768px** - Стандартные смартфоны (iPhone, Samsung Galaxy)

### 📱 Планшеты
- **769px - 1024px** - iPad, Android планшеты (портретная ориентация)
- **1024px+** - Планшеты в ландшафтной ориентации

### 💻 Десктоп
- **1025px - 1439px** - Стандартные ноутбуки
- **1440px - 1919px** - Большие мониторы
- **1920px+** - 4K и выше

## Основные улучшения

### 1. Сайдбар (Sidebar)
✅ Автоматически скрывается на мобильных (< 768px)
✅ Адаптивная ширина: 220px (планшет) → 260px (десктоп) → 280px (большие экраны)
✅ Плавное сворачивание/разворачивание
✅ Календарь автоматически скрывается при сворачивании

### 2. Мобильный сайдбар (MobileSidebar)
✅ Выдвижное меню с затемнением фона
✅ Адаптивная ширина: 85% (телефоны) → 300px (планшеты)
✅ Поддержка безопасной зоны iPhone (notch)
✅ Плавная анимация открытия/закрытия

### 3. Календарь (MiniCalendar)
✅ Адаптивные размеры ячеек
✅ Оптимизированные отступы для разных экранов
✅ Touch-friendly кнопки (минимум 32px)
✅ Читаемость на всех размерах экрана

### 4. Компоненты (Clients, Documents, Calendar)
✅ Адаптивные сетки (3 колонки → 2 → 1)
✅ Увеличенные кнопки для touch-устройств (минимум 44px)
✅ Адаптивная типографика
✅ Оптимизированные отступы

## Технические детали

### Breakpoints
```css
/* Маленькие телефоны */
@media (max-width: 375px) { }

/* Стандартные телефоны */
@media (max-width: 480px) { }

/* Большие телефоны / маленькие планшеты */
@media (max-width: 768px) { }

/* Планшеты */
@media (max-width: 1024px) and (min-width: 769px) { }

/* Большие экраны */
@media (min-width: 1440px) { }

/* 4K и выше */
@media (min-width: 1920px) { }
```

### Touch-оптимизация
```css
@media (hover: none) and (pointer: coarse) {
  /* Минимальный размер кликабельных элементов */
  button { min-height: 44px; min-width: 44px; }
  
  /* Предотвращение зума на iOS */
  input { font-size: 16px !important; }
}
```

### Безопасная зона (iPhone с вырезом)
```css
@supports (padding: max(0px)) {
  .container {
    padding-left: max(24px, env(safe-area-inset-left));
    padding-right: max(24px, env(safe-area-inset-right));
  }
}
```

### Плавные переходы
```css
* {
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}
```

## Поддержка

При возникновении проблем с адаптивностью:
1. Проверьте viewport meta tag
2. Очистите кеш браузера
3. Проверьте консоль на ошибки
4. Протестируйте в другом браузере
