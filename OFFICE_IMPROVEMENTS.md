## 🎯 Как использовать

### Базовое использование
Анимации применяются автоматически после импорта CSS файла.

### Добавление анимаций к новым элементам
```css
.my-element {
  animation: fadeIn 0.5s ease-out;
}
```

### Классы-утилиты
- `.fade-in-up` - появление снизу
- `.slide-in-left` - появление слева
- `.slide-in-right` - появление справа
- `.scale-in` - масштабирование
- `.skeleton` - эффект загрузки

## 🔧 Настройка

### Изменение скорости анимаций
```css
:root {
  --animation-speed-fast: 0.2s;
  --animation-speed-normal: 0.3s;
  --animation-speed-slow: 0.5s;
}
```

### Отключение анимаций
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
```

## 📝 Рекомендации

1. **Производительность**
   - Используйте `will-change` для часто анимируемых элементов
   - Избегайте анимации свойств, вызывающих reflow
   - Предпочитайте `transform` и `opacity`

2. **Доступность**
   - Учитывайте `prefers-reduced-motion`
   - Обеспечьте альтернативы для анимаций
   - Не полагайтесь только на анимации для передачи информации

3. **UX**
   - Не переусердствуйте с анимациями
   - Используйте последовательные timing functions
   - Тестируйте на реальных устройствах
