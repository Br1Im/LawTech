# Обновление дизайна CRM системы

## Что было сделано

### 1. Создан новый сайдбар с календарём
- **Sidebar.tsx** - основной сайдбар для десктопа с:
  - Мини-календарём в верхней части
  - Навигационным меню
  - Кнопкой сворачивания/разворачивания
  - Профилем пользователя внизу

- **MiniCalendar.tsx** - компактный календарь в сайдбаре:
  - Навигация по месяцам
  - Выделение текущего дня
  - Выбор даты
  - Поддержка светлой и тёмной темы

- **MobileSidebar.tsx** - мобильная версия сайдбара:
  - Выдвижное меню слева
  - Полноэкранное затемнение фона
  - Все пункты меню

- **HamburgerButton.tsx** - кнопка-гамбургер для мобильных устройств

### 2. Улучшен дизайн компонентов
- Обновлены стили для Clients, Documents, Calendar
- Более современный и чистый вид
- Улучшена типографика
- Добавлены плавные переходы и анимации

### 3. Обновлена цветовая схема
- Светлая тема: более мягкие оттенки серого (#f5f5f7)
- Тёмная тема: глубокий чёрный (#1a1a1a)
- Акцентный цвет: золотой (#d4af37)
- Улучшена читаемость текста

### 4. Адаптивность
- Полная поддержка мобильных устройств
- Адаптивная сетка для планшетов
- Оптимизация для разных размеров экрана

## Структура файлов

```
frontend/src/components/ui/
├── Sidebar.tsx              # Основной сайдбар
├── Sidebar.css              # Стили сайдбара
├── MiniCalendar.tsx         # Мини-календарь
├── MiniCalendar.css         # Стили календаря
├── MobileSidebar.tsx        # Мобильный сайдбар
├── MobileSidebar.css        # Стили мобильного сайдбара
├── HamburgerButton.tsx      # Кнопка меню
└── HamburgerButton.css      # Стили кнопки
```

## Как запустить

### Локальный запуск frontend

```bash
cd frontend
npm install
npm run dev
```

### Запуск через Docker

```bash
docker-compose up --build
```

## Особенности

### Календарь в сайдбаре
- Отображается только в развёрнутом состоянии сайдбара
- Автоматически скрывается при сворачивании
- Поддерживает выбор даты
- Синхронизирован с основным календарём

### Темы
- Автоматическое переключение между светлой и тёмной темой
- Плавные переходы при смене темы
- Сохранение выбранной темы в localStorage

### Мобильная версия
- Выдвижное меню с анимацией
- Затемнение фона при открытии
- Закрытие по клику вне меню
- Кнопка-гамбургер с анимацией

## Технологии

- React 18
- TypeScript
- CSS Variables для тем
- Day.js для работы с датами
- React Icons для иконок
