### Что нужно:
- Сервер с Ubuntu/Debian
- SSH доступ
- 10 минут времени

### Команды:

```bash
# 1. Подключитесь к серверу
ssh root@217.26.31.98

# 2. Установите Docker
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
apt install -y docker-compose

# 3. Клонируйте проект
cd /var/www
git clone <URL_вашего_репозитория> lawtech
cd lawtech

# 4. Запустите
docker-compose up -d

# 5. Проверьте
docker-compose ps
```

## 🔒 Важно для безопасности!

После развертывания обязательно:

1. **Смените все пароли**
   ```bash
   # В файле server/.env измените:
   - DB_PASSWORD
   - JWT_SECRET
   ```

2. **Настройте Firewall**
   ```bash
   ufw allow 22/tcp
   ufw allow 80/tcp
   ufw allow 443/tcp
   ufw enable
   ```

3. **Установите SSL** (если есть домен)
   ```bash
   apt install -y certbot python3-certbot-nginx
   certbot --nginx -d your-domain.com
   ```
