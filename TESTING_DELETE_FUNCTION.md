# Тестирование функции удаления договора

## Исправленные проблемы:

### 1. Видимость кнопки удаления
- ✅ Добавлены CSS стили с `!important` для обеспечения видимости
- ✅ Кнопка теперь имеет красный цвет и иконку мусорной корзины
- ✅ Добавлены стили для hover эффекта

### 2. Ошибка "Failed to delete document"
- ✅ Исправлено использование `editedDocument` вместо `selectedDocument`
- ✅ Добавлено логирование для отладки
- ✅ Улучшена обработка ошибок

## Как протестировать:

1. **Откройте приложение**: http://localhost:5173
2. **Войдите в систему** с любыми учетными данными
3. **Найдите любой договор** в списке
4. **Нажмите на иконку карандаша** (редактирование)
5. **В модальном окне найдите красную кнопку с мусорной корзиной**
6. **Нажмите на кнопку удаления**
7. **Подтвердите удаление** в диалоговом окне

## Ожидаемый результат:
- Кнопка удаления должна быть видна (красная с иконкой)
- При нажатии должно появиться подтверждение
- После подтверждения договор должен быть удален
- Должно появиться сообщение "Договор успешно удален!"
- Модальное окно должно закрыться
- Договор должен исчезнуть из списка

## Отладка:
Если есть проблемы, откройте консоль браузера (F12) и посмотрите на логи:
- Должно быть сообщение "Удаление документа с ID: [номер]"
- Должно быть сообщение "Ответ сервера: [статус]"

## Технические детали:
- Функция использует `editedDocument` для получения ID документа
- API endpoint: `DELETE /api/legal-documents/:id`
- Требуется авторизация (Bearer token)
- После успешного удаления обновляется локальный массив документов
