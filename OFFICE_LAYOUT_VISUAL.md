## 🎯 Выравнивание

### Горизонтальное
- Все блоки одинаковой ширины
- Равные отступы между блоками
- Центрирование контента

### Вертикальное
- Минимальная высота: 325px

- Равная высота в строке

## ✨ Анимации

### При загрузке
```
0.1s: Блок 1 появляется (slideInLeft)
0.2s: Блок 2 появляется (slideInRight)
0.3s: Блок 3 появляется (slideInLeft)
0.4s: Блок 4 появляется (slideInRight)
```

### При наведении
```
Transform: translateY(-4px)
Box-shadow: увеличивается
Duration: 0.3s
```

## 🔄 Интерактивность

### Кнопки расширения
- Позиция: top-right каждого блока
- Вращение: -45°
- Hover: scale(1.2) + rotate
- Click: открывает модальное окно

### Модальные окна
- Blur-эффект фона
- Плавное появление
- Детальная информация
- Закрытие по ESC или клику вне

## 📊 Данные в блоках

### Блок 1
- Список офисов (до 3)
- Приходы (число)
- Общая касса (рубли)
- Процент изменения

### Блок 2
- График по дням/периодам/месяцам
- Легенда
- Значения выручки
- Интерактивные подсказки

### Блок 3
- Список сотрудников
- Касса за день
- Касса за период
- Сортировка по выручке

### Блок 4
- Круговая диаграмма
- Только юристы/адвокаты
- Проценты от общей суммы
- Цветовая кодировка
