## 📝 Технические детали

### Сохранение темы:
```typescript
useEffect(() => {
  const theme = isDarkTheme ? 'dark' : 'light';
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem('theme', theme); // Сохраняем в localStorage
}, [isDarkTheme]);
```

### Восстановление темы:
```typescript
const [isDarkTheme, setIsDarkTheme] = useState<boolean>(() => {
  const savedTheme = localStorage.getItem('theme'); // Читаем из localStorage
  if (savedTheme) {
    return savedTheme === 'dark';
  }
  return document.documentElement.getAttribute('data-theme') === 'dark';
});
```

## 🔍 Где хранится тема

Тема сохраняется в **localStorage** браузера:
- **Ключ:** `theme`
- **Значение:** `'light'` или `'dark'`

### Проверить в DevTools:
1. Открой DevTools (F12)
2. Перейди во вкладку **Application** (Приложение)
3. Слева выбери **Local Storage** → **http://localhost**
4. Найди ключ `theme`
5. Значение должно быть `'light'` или `'dark'`

## 🔄 Как сбросить тему

Если нужно сбросить сохранённую тему:

### Вариант 1: Через DevTools
1. F12 → Application → Local Storage
2. Найди ключ `theme`
3. Удали его

### Вариант 2: Через консоль
```javascript
localStorage.removeItem('theme');
location.reload();
```

### Вариант 3: Очистить весь localStorage
```javascript
localStorage.clear();
location.reload();
```
