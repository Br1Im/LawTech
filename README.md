Legal technology platform - automation of legal processes and document management.

## Tech Stack

- **React**
- **Vite**
- **TypeScript**
- **Python**
- **Docker**
- **Redux**
- **Nginx**

## Features

- Document automation
- Legal analytics
- Case management
- Document templates

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn
- [Python](https://www.python.org/) (3.10+)
- [Docker](https://www.docker.com/)

### Installation

```bash
git clone https://github.com/Br1Im/LawTech.git
cd LawTech
npm install
pip install -r server/scripts/requirements.txt
```

### Running

```bash
npm run dev
```
