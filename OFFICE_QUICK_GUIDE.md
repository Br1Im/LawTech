## 🔧 Как использовать

### Базовое использование
Все стили применяются автоматически после импорта:

```tsx
import "./OfficeContent.css";
import "./OfficeAnimated.css";
import "./OfficeMobile.css";
```

### Добавление анимации к элементу
```tsx
<div className="my-element fade-in-up">
  {/* контент */}
</div>
```

### Последовательное появление
```tsx
{items.map((item, index) => (
  <div 
    key={item.id}
    className="scale-in"
    style={{ animationDelay: `${index * 0.1}s` }}
  >
    {/* контент */}
  </div>
))}
```


### Отключение анимаций
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation: none !important;
    transition: none !important;
  }
}
```

## 🐛 Решение проблем

### Анимации не работают
1. Проверьте импорт CSS файлов
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте консоль на ошибки

### Некорректное отображение на мобильных
1. Проверьте viewport meta tag
2. Убедитесь, что все CSS файлы загружены
3. Проверьте поддержку браузера

### Медленные анимации
1. Проверьте производительность устройства
2. Отключите сложные эффекты
3. Используйте `prefers-reduced-motion`

```tsx
// В компоненте
<div className="my-new-element">

.my-new-element {
  animation: fadeIn 0.5s ease-out;
  transition: all 0.3s ease;
}

.my-new-element:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 16px rgba(0, 0, 0, 0.1);
}
```

### Условная анимация
```tsx
<div className={`office-card ${isSelected ? 'selected' : ''}`}>
  {/* контент */}
</div>
```

### Динамическая задержка
```tsx
{items.map((item, index) => (
  <div 
    key={item.id}
    style={{ 
      animation: 'fadeIn 0.5s ease-out',
      animationDelay: `${index * 0.1}s`,
      animationFillMode: 'both'
    }}
  >
    {/* контент */}
  </div>
))}
```

## 🎓 Лучшие практики

- Не забывайте про accessibility
