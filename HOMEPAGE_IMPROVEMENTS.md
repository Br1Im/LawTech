## 📝 Использование

### Добавление новой анимированной секции:

```tsx
import styled from '@emotion/styled';
import { keyframes } from '@emotion/react';

const fadeIn = keyframes`
  from { opacity: 0; transform: translateY(30px); }
  to { opacity: 1; transform: translateY(0); }
`;

const Container = styled.section`
  animation: ${fadeIn} 1s ease forwards;
`;

const MySection = () => {
  return (
    <Container>
      {/* Ваш контент */}
    </Container>
  );
};
```

### Добавление hover эффекта:

```tsx
const Card = styled.div`
  transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);

  &:hover {
    transform: translateY(-10px);
    box-shadow: 0 20px 40px rgba(212, 175, 55, 0.2);
  }
`;
```

## 🐛 Исправленные проблемы

### 1. Изображение в кружке
**Проблема**: Изображение было смещено и не центрировано
**Решение**: 
```css
width: 100%;
height: 100%;
object-fit: cover;
object-position: center;
```

### 2. Адаптивность на мобильных
**Проблема**: Элементы выходили за границы экрана
**Решение**: Добавлены media queries для всех breakpoints

### 3. Производительность анимаций
**Проблема**: Анимации тормозили на слабых устройствах
**Решение**: Использование GPU-ускоренных свойств (transform, opacity)
