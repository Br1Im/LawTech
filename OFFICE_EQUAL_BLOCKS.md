# ✅ Выравнивание блоков вкладки "Офис"

## 🎯 Задача
Сделать все 4 блока абсолютно одинаковыми по размеру (ширине и высоте).

## ❌ Проблема
Блоки были разной высоты и ширины:
- Блок 1 (верхний левый) был выше остальных
- Блоки не выравнивались по высоте
- Разные отступы между блоками

## ✅ Решение

### 1. Фиксированная сетка с равными ячейками
```css
.main-content-wrapper {
  display: grid;
  grid-template-columns: 1fr 1fr;      /* 2 равные колонки */
  grid-template-rows: 1fr 1fr;         /* 2 равные строки */
  height: calc(100vh - 200px);         /* Фиксированная высота */
  gap: 12px;
  align-items: stretch;
}
```

**Ключевые изменения:**
- `grid-template-rows: 1fr 1fr` вместо `minmax(400px, auto)`
- `height: calc(100vh - 200px)` для фиксированной высоты
- `align-items: stretch` для растягивания блоков

### 2. Одинаковые стили для всех блоков
```css
.office-left-column,
.chart-box-container,
.employee-table-container-container,
.charts-container {
  width: 100%;
  height: 100%;
  box-sizing: border-box;
  overflow: hidden;
}
```

### 3. Убраны лишние отступы
```css
/* Удалено */
.chart-box-container {
  margin-left: 20px;  /* ❌ */
}

.employee-table-container-container {
  margin-right: 20px;  /* ❌ */
}
```

### 4. Правильные размеры для внутренних элементов
```css
.chart-box,
.employee-table-container {
  width: 100%;
  height: 100%;
  overflow: hidden;
  display: flex;
  flex-direction: column;
}
```

## 🔧 Технические детали

### Grid Layout
- **Тип**: CSS Grid
- **Колонки**: 2 (1fr 1fr)
- **Строки**: 2 (1fr 1fr)
- **Gap**: 12px
- **Высота**: calc(100vh - 200px)

### Блоки
- **Позиционирование**: grid-column, grid-row
- **Размеры**: 100% width, 100% height
- **Overflow**: hidden (для прокрутки внутри)
- **Box-sizing**: border-box

### Внутренние элементы
- **Chart-box**: flex column, 100% height
- **Employee-table**: flex column, 100% height
- **Canvas**: max-width 100%, height auto
