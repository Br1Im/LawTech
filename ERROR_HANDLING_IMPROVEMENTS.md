## 🔧 Отладка

### Как проверить ошибки:

1. **Откройте консоль браузера** (F12)
2. **Попробуйте войти** с неверными данными
3. **Смотрите логи**:

```
🔐 Попытка входа: { email: "test@test.com" }
📡 URL запроса: http://localhost:3001/api/auth/login
📥 Ответ сервера: 401 Unauthorized
❌ Ошибка от сервера: { error: "Invalid credentials" }
❌ Ошибка входа: Error: ❌ Неверный email или пароль
```

### Типичные проблемы:

#### 1. Сервер не запущен
```
❌ Не удалось подключиться к серверу. 
   Проверьте, что сервер запущен на порту 3001
```

**Решение**: Запустите сервер
```bash
cd server
npm start
```

#### 2. Неверный порт
```
❌ Сервер недоступен. Проверьте подключение
```

**Решение**: Проверьте `frontend/src/shared/config/constants.ts`:
```typescript
export const API_BASE_URL = 'http://localhost:3001/api';
```

#### 3. CORS ошибка
```
Access to fetch at 'http://localhost:3001/api/auth/login' 
from origin 'http://localhost:5173' has been blocked by CORS policy
```

**Решение**: Проверьте `server/server.js`:
```javascript
app.use(cors({
  origin: ['http://localhost:5173'],
  credentials: true
}));
```

## 🎯 Примеры использования

### 1. Базовая обработка ошибки:

```typescript
try {
  const response = await fetch(apiUrl, options);
  if (!response.ok) {
    throw new Error('Ошибка запроса');
  }
  const data = await response.json();
  message.success('✅ Успешно!');
} catch (error) {
  console.error('❌ Ошибка:', error);
  message.error('❌ Что-то пошло не так', 5);
}
```

### 2. С определением типа:

```typescript
try {
  // ... запрос
} catch (error) {
  if (error instanceof TypeError && error.message.includes('fetch')) {
    message.error('❌ Проблема с сетью', 5);
  } else if (error instanceof Error) {
    message.error(error.message, 5);
  } else {
    message.error('❌ Неизвестная ошибка', 5);
  }
}
```

### 3. С компонентом ErrorDisplay:

```typescript
const [error, setError] = useState<string | null>(null);

try {
  // ... запрос
} catch (error) {
  setError((error as Error).message);
}

return (
  <>
    {error && (
      <ErrorDisplay 
        message={error}
        onClose={() => setError(null)}
      />
    )}
    {/* Остальной контент */}
  </>
);
```
